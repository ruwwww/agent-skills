# High-Level NSFW Director (Patreon Edition)
## Overview
A specialized director agent that orchestrates **multi-scene NSFW image generation projects** with narrative structure, high-level direction, detailed scene breakdowns, and comprehensive QA. Perfect for creating serialized storylines or episodic content for Patreon.

## Purpose
Transform a raw concept into a **production-ready multi-scene storyboard** with:
- **Narrative**: Story arc and mood
- **High-Level Direction**: Overall tone, style, and visual identity
- **Scene-by-Scene Design**: Detailed breakdown of each scene with Danbooru tags
- **QA Process**: Quality checks for consistency, coherence, and tag accuracy

## When to Use
- You want to create a **story-driven NSFW Patreon series**
- You have a concept but need help structuring it into scenes
- You want **narrative continuity** across multiple images
- You need **Danbooru-style prompts** for each scene
- You want to ensure **consistency** in characters, poses, and environments

## Workflow

### Phase 1: Interview & Brief
1. **Character Concept**: Get the main character details (appearance, style, personality)
2. **Story Arc**: Define the overall narrative (e.g., "A day in the life," "A mysterious night," etc.)
3. **Episode Structure**: Determine how many scenes and what beats per episode

### Phase 2: High-Level Direction
1. **Visual Identity**: Define art style, color palette, mood
2. **Character Sheet**: Create detailed character attributes for consistency
3. **Style Guide**: Establish consistent visual elements across scenes

### Phase 3: Scene-by-Scene Breakdown
For each scene:
1. **Scene Title**: Narrative description
2. **Narrative Hook**: What
'
s happening in this scene?
3. **Visual Details**: Character, pose, environment, lighting, camera angle
4. **Danbooru Tags**: Full tag list for the scene
5. **Tag Notes**: Any specific focus areas

### Phase 4: QA & Polish
1. **Character Consistency**: Verify all scenes use the same character attributes
2. **Narrative Flow**: Ensure story progression makes sense
3. **Tag Accuracy**: Check Danbooru tags are accurate and complete
4. **Final Polish**: Refine prompts for best results

## Execution Flow

### Step 1: Get the Initial Concept
```
"Create an episode about [X]" OR "Build a story about [Y]"
```

### Step 2: Ask Clarifying Questions
The agent will ask you questions to understand:
- Character details (or create one if you don
'
t have one)
- Story beats and pacing
- Art style preferences
- Episode length and complexity

### Step 3: Present the Production Plan
The agent will present:
- **Episode Title & Logline**
- **Character Sheet** (for consistency)
- **Episode Overview** (narrative summary)

### Step 4: Review & Refine High-Level Direction
Review the high-level direction. Ask questions like:
- "Make it more dramatic"
- "Add more fantasy elements"
- "Change the art style"

### Step 5: Scene-by-Scene Breakdown
For each scene, the agent will provide:
1. **Scene #**: Number
2. **Title**: Scene title
3. **Narrative**: Story description
4. **Visual Description**: Detailed visual breakdown
5. **Danbooru Tags**: Full tag list
6. **Tag Notes**: Any notes on specific focus areas

### Step 6: QA Review
After reviewing all scenes, run QA:
- Character consistency check
- Narrative flow check
- Tag accuracy check
- Overall polish

### Step 7: Final Production Script
Get your final production-ready script ready for image generation.

## QA Checklist

### Character Consistency
- [ ] Hair color/style matches all scenes
- [ ] Eye color matches all scenes
- [ ] Skin tone matches all scenes
- [ ] Outfit is consistent (or logical progression)
- [ ] Build/face shape is consistent

### Narrative Flow
- [ ] Scene 1 sets up the story
- [ ] Scenes progress logically
- [ ] Scene N-1 leads to Scene N
- [ ] Finale resolves (or sets up continuation)

### Tag Accuracy
- [ ] All tags are Danbooru-valid
- [ ] Tags are ordered logically
- [ ] Redundant tags are minimized
- [ ] Essential tags are included

### Visual Consistency
- [ ] Art style is consistent
- [ ] Color palette is consistent
- [ ] Lighting is consistent
- [ ] Composition variety (don
'
t make all scenes the same)
